# Cognos Node

## Description

Cognos Node feature provides the node information such as CPU, Memory, PCI device information.

### Supported OS List

- Oracle Linux 10
- Rockylinux 9
- Ubuntu 22.04
- Ubuntu 24.04

## Build

node is built and tested with the rest of Cognos, from the repository root: see
[Build](../../README.md#build) (`./build.sh node`, and `./build.sh --test node` for its unit tests).
