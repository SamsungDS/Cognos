# Cognos RAS

## Description

Cognos RAS is a feature module of Cognos, providing the CXL memory related RAS functionality.

### Supported OS List

- Rockylinux 9
- Ubuntu 22.04
- Ubuntu 24.04

## Build

ras is built and tested with the rest of Cognos, from the repository root: see
[Build](../../README.md#build) (`./build.sh ras`, and `./build.sh --test ras` for its unit tests).
